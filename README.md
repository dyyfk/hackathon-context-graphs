# Hackathon: Context Graphs for Multi-Agent AI

Side-by-side demo showing how a Neo4j context graph + Cypher-generating agent beats vanilla vector RAG on structured questions over Stack Overflow Q&A.

Built for the [Hack Day at AWS Builder Loft SF, May 19 2026](https://luma.com/bchosur4) using patterns from the [AWS "stop AI agent hallucinations" workshop](https://github.com/aws-samples/sample-stop-ai-agent-hallucinations-workshop).

## What it shows

Two agents answer the same questions over the same Stack Overflow corpus:

- **Vanilla RAG** — FAISS vector search over 1,000 question/answer passages, top-3 retrieval.
- **Graph-RAG** — Cypher generated by the LLM, executed against a Neo4j knowledge graph (1,589 questions, 1,367 answers, 1,365 users, 476 tags).

Both wrap Claude Sonnet 4.5 (`us.anthropic.claude-sonnet-4-5-20250929-v1:0`) on **Amazon Bedrock** via [Strands Agents](https://strandsagents.com).

| # | Question type | Vanilla RAG | Graph-RAG |
|---|---|---|---|
| 1 | Count of cypher questions with accepted answers | "I cannot — query Stack Exchange directly." | **467** |
| 2 | Users who answered 'cypher' AND asked 'java' | "I cannot — query Stack Exchange directly." | 9 users, listed by name |
| 3 | Top 5 tags co-occurring with 'neo4j-apoc' | "I cannot — query Stack Exchange directly." | neo4j 122, cypher 86, graph-databases 9, graph-data-science 4, csv 4 |
| 4 | Cypher questions with >50,000 views (**Antarctica test**) | "I cannot get view counts" | **0** — and proves it with the real ceiling (1,851 views, named question) |

In every case, vanilla RAG capitulates and tells you to query the source database directly. Graph-RAG just runs the Cypher and gives the number. In the empty case (Q4), Graph-RAG doesn't just say "no results" — it returns the actual max to prove the empty answer is correct.

## Architecture

```
                   ┌─────────────────────┐
                   │ Claude Sonnet 4.5   │  ← Amazon Bedrock
                   │ (via Strands)       │     (us-east-1)
                   └──────────┬──────────┘
                              │
                ┌─────────────┴──────────────┐
                ▼                            ▼
   ┌──────────────────────┐      ┌───────────────────────┐
   │  search_questions    │      │ query_knowledge_graph │
   │  (FAISS + MiniLM)    │      │  (Cypher)             │
   └──────────────────────┘      └───────────────────────┘
                │                            │
                ▼                            ▼
       passages (top-3)             Neo4j Sandbox
                                    (Stack Overflow graph)
```

## Setup

Prereqs:
- Python 3.10+
- A Neo4j Sandbox at https://sandbox.neo4j.com — pick the **Stack Overflow** project
- An AWS account with Bedrock access to Claude Sonnet 4.5 in `us-east-1`

Bedrock notes:
- Foundation models auto-enable on first invoke (the legacy "Model access" page is retired).
- First real invoke may return `ResourceNotFoundException: Model use case details have not been submitted`. Open the Bedrock console → Model catalog, click "Submit use case details", fill in the Anthropic form — activation takes ~5 min.
- Recommended IAM: create an IAM user (e.g. `graphrag-demo`) with `AmazonBedrockFullAccess` rather than root access keys.

```bash
git clone https://github.com/dyyfk/hackathon-context-graphs
cd hackathon-context-graphs

cp .env.example .env
# Fill in:
#   NEO4J_URI, NEO4J_USER, NEO4J_PASSWORD     (from sandbox "Connection details")
#   AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY  (IAM user, Bedrock-permitted)
#   AWS_REGION=us-east-1

python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python discover.py     # validate connection + dump real schema
```

## Run the demo

**Streamlit UI** (recommended) — side-by-side comparison, generated Cypher visible, latency badges, free-form input:

```bash
streamlit run app.py
# Open http://localhost:8501
```

**CLI version** — runs the 4 hero queries through both agents and prints results:

```bash
python compare.py
```

First run builds the FAISS index over 1,000 questions (~30s) and caches it to `_rag_index.faiss`.

## Files

| File | Purpose |
|---|---|
| `app.py` | Streamlit side-by-side UI |
| `compare.py` | CLI: runs both agents through the 4 hero queries |
| `graph.py` | Neo4j connection + `run_cypher` helper |
| `model.py` | Strands `BedrockModel` config |
| `discover.py` | Schema introspection — run first to verify setup |
| `graph_agent.py` | Graph-RAG agent (Strands + Cypher tool) |
| `rag_agent.py` | Vanilla RAG agent (Strands + FAISS tool) |
| `viz.html` | Standalone Cypher-traversal visualizer (open in browser) |

## Switching domains

The Stack Overflow sandbox is one of ~15 pre-built Neo4j Sandbox graphs (Crime Investigation, Paradise Papers, Movies, Twitter, etc.). To target a different one:

1. Provision the sandbox at sandbox.neo4j.com
2. Update `.env` with its connection details
3. Run `python discover.py` and copy the actual schema into the system prompt in `graph_agent.py`
4. Rewrite the 4 queries in `compare.py` and `app.py`'s `QUERIES` list against the new schema
